REST API Generator

What is a REST API?

REST APIs are web-based Application Programming Interfaces (APIs) providing clients with an easy means to access and update data sourced by a data provider. A key characteristic of REST APIs is that they expose business data resources (aka business data objects) that can be created, read, updated, and/or deleted by the API. When developing a REST API an important first step is to create a business domain model identifying the data resources, resource attributes, and relationships between resources. The business domain model is the main design artifact defining the API's interface between the data provider and its clients from a business perspective.

What does the REST API Generator tool do?

The REST API Generator provides two important capabilities to greatly reduce API development effort. First it transforms a business domain model expressed as a UML class diagram into an API interface specification documented using the OpenAPI standard. An OpenAPI specification is a machine-readable document describing the API's endpoints, request and response formats, and other API details needed by clients to know how to call the API.

Second the REST API Generator processes an API's OpenAPI specification to generate code implemementing the API's skeleton infrastructure. The skeleton implementation is a fully functional API that can receive requests from the client and return default responses but contains stubs for the business logic. The API skeleton code provides API developers with an initial "quick start" code base, thus significantly reducing the time and effort required to develop a REST API.

In short by using the REST API Generator development activities that used to take weeks to perform manually can now be accomplished automatically in a matter of minutes. Instead of developers spending time to manually create API specifications and write API boilerplate code they can now focus on implementing the API's business logic to more quickly realize the API's business value proposition.

What are the steps to create a new REST API?

The process of creating a new REST API using the REST API Generator consists of the following six steps:

  1. Obtain an access token enabling you to utilize the REST API Generator.
  2. Create a business domain model expressed as a UML class diagram.
  3. Generate the API's OpenAPI interface specification.
  4. Tailor the API's specification to remove unwanted endpoints.
  5. Generate the API's skeleton implementation.
  6. Implement the API's business logic.

Obtain an access token

To use the REST API Generator you must first obtain an access token. The access token enables access to the REST API Generator tool for a specified time period. View the various access plans offered to select one that best meets your needs.

Create the business domain model

Use the StarUML modeling tool to create a UML class diagram representing the API's business domain model. The business domain model should identify the data resources exposed by the API, resource attributes, and relationships between resources. Once the business domain model has been created save it to your local computer using StarUML's native .mdj file format.

Generate the API's OpenAPI interface specification

Open the REST API Generator tool, upload the StarUML .mdj file containing the API's business domain model, and then press the Generate API button. In response the tool will generate the API's specification document and download it to your local computer.

Tailor the API's specification to remove unwanted endpoints

After the API interface specification has been generated and downloaded it can then be tailored to remove unwanted endpoints. For example, if the business domain model does not require a DELETE endpoint for a particular resource then the DELETE endpoint can be removed from the API specification.

Generate the API's skeleton implementation

After the API's specification has been tailored it can then be used to generate code comprising the API's skeleton implementation. The skeleton implementation is a fully functional API that can receive requests from the client and return default responses. The API is considered a skeleton implementation in that it contains stubs for the business logic. The intent is to serve as a starting point for API developers to implement the business logic.

To generate the API's skeleton implementation code open the REST API Generator tool, upload the OpenAPI specification file, and then press the Implement API button. In response the tool will generate the API's skeleton implementation files, package them into a ZIP file, and download the ZIP file to your local computer

Implement the API's business logic

Once the API's skeleton implementation is generated it is then ready to be used as a starting point for API developers to implement the business logic. The skeleton implementation provides a quick-start code base that significantly reduces the time and effort required to develop a REST API.
